# GuildDoodle

A shared pixel canvas for your guild. Place one pixel at a time on a small grid, watch the guild collaborate (or troll) over time. r/place, but cozy.

Requested via Discord by deehoc.

## Slash commands

- `/doodle` — open the canvas
- `/gd` — short alias
